# Security Policy

This portfolio repository contains only synthetic data and no production credentials.

## Reporting an issue

If you identify an exposed secret, vulnerable dependency, or unsafe configuration, open a private security advisory rather than a public issue.

## Data policy

Do not commit:

- access keys, tokens, passwords, or connection strings
- personal data
- confidential employer or customer information
- production database extracts

Local environment files, caches, and temporary outputs are excluded through `.gitignore`.
