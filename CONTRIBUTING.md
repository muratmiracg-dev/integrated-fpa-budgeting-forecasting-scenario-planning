# Contributing

This repository is a personal portfolio project. Suggestions and issue reports are welcome.

## Development workflow

1. Create a feature branch.
2. Keep financial logic and presentation changes in separate commits where practical.
3. Run `make pipeline`, `make lint`, and `make test`.
4. Confirm `Data/validation_report.json` reports 17 of 17 passing checks.
5. Open a pull request describing the business impact, model impact, and validation evidence.

Do not add confidential, personal, or production company data.
