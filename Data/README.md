# Data package

All records in this project are synthetic and created for portfolio demonstration.
No customer, employee, supplier, bank-account or company-confidential data is included.

## Coverage

- Actuals: January 2023 to June 2026
- FY2026 budget: January to December 2026
- Q2 rolling forecast: January 2026 to June 2027
- Reporting currency: TRY
- Planning grain: month, account, cost center, department, business unit and region

## Primary fact tables

- `fact_actuals.csv`: synthetic ERP actuals
- `fact_budget.csv`: approved FY2026 budget
- `fact_forecast.csv`: Q2 2026 rolling forecast with closed actuals
- `fact_scenario.csv`: Base, Upside, Downside and Stress scenario ledger
- `fact_working_capital.csv`: AR, inventory, AP and cash-conversion metrics
- `fact_cash_flow.csv`: cash roll-forward by version
- `fact_headcount.csv`: FTE, hires, exits, payroll and benefits
- `fact_capex.csv`: project spend, depreciation and remaining NBV

## Analytical outputs

The model-comparison, variance, scenario, Monte Carlo, department, business-unit
and executive KPI files are generated by the Python pipeline. Run:

```bash
PYTHONPATH=Python/src python -m fpa_system.run_pipeline
```
