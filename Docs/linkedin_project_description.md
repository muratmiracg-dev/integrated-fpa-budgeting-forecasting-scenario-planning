# LinkedIn Project Copy

## Project name

**Integrated FP&A Budgeting, Forecasting & Scenario Planning System**

## Tools used

Python, SQL, Power BI, DAX, Power Query, Microsoft Excel, PBIP, pandas, NumPy, scikit-learn, statsmodels, SQLite, Monte Carlo Simulation, Financial Modeling, Data Visualization

## Description — under 2,000 characters

Developed an end-to-end Integrated FP&A Budgeting, Forecasting & Scenario Planning System that transforms fragmented financial and operational data into a governed, forward-looking management framework.

- Created a synthetic multi-dimensional dataset for Asteria Consumer Group covering 42 months of actuals, a detailed FY2026 budget, and an 18-month rolling forecast. Modeled revenue, COGS, opex, EBITDA, net income, cash flow, working capital, workforce, capex, departments, business units, and operating drivers.

- Built a reproducible Python and SQL pipeline for data generation, financial statements, variance analysis, forecasting, reporting, and validation. Evaluated four forecast models using MAE, RMSE, WAPE, and bias; selected one governed champion for each business unit.

- Developed Upside, Base, Downside, and Stress scenarios connecting revenue, margin, cost, working-capital, investment, and liquidity assumptions. Added a 5,000-trial Monte Carlo simulation to quantify ranges, downside probability, and cash risk.

- Designed a 31-sheet formula-driven Excel FP&A model and an 11-page Power BI PBIP dashboard with embedded data, a semantic model, reusable DAX measures, monthly filtering, P&L, budget variance, rolling forecast, department, business-unit, cash, and risk analysis.

- Implemented controls for P&L identities, cash roll-forward, working-capital reconciliation, scenario hierarchy, model governance, and data coverage. All 17 project controls and 5 unit tests pass.

- Delivered English and Turkish 20-slide presentations, a 12-page vector HD report, portfolio images, a SQLite database, documentation, and a GitHub-ready structure.

The solution enables management to compare actuals with budget, refresh the outlook, explain performance drivers, protect liquidity, evaluate investment decisions, and act early under downside scenarios.
