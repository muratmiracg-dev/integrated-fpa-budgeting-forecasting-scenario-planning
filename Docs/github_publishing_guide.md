# GitHub Publishing Guide

Do not publish before completing the final local approval.

## Recommended repository name

`integrated-fpa-budgeting-forecasting-scenario-planning`

## GitHub description

End-to-end FP&A planning system combining budgeting, rolling forecasts, P&L, cash flow, working capital, scenario analysis, Monte Carlo risk, Power BI, Excel, SQL, and Python.

## Suggested topics

`fpa`, `financial-planning`, `budgeting`, `forecasting`, `scenario-planning`, `power-bi`, `dax`, `power-query`, `excel`, `python`, `sql`, `business-intelligence`, `monte-carlo`, `financial-modeling`, `data-analytics`

## Before publishing

1. Review the README and portfolio images.
2. Confirm the author name and LinkedIn copy.
3. Confirm that only synthetic data is included.
4. Run the final quality commands.
5. Commit the project as one reviewed release.
6. Add repository topics and an About description.
7. Create a `v1.0.0` release containing the key download files.

## Suggested initial commit

Summary:

`Build integrated FP&A budgeting and forecasting platform`

Description:

`Add the Python/SQL planning engine, synthetic finance data, Excel model, Power BI PBIP report, bilingual presentations, vector executive PDF, automated controls, and technical documentation.`

## Suggested release title

`v1.0.0 — Professional FP&A Portfolio Release`

## Important

Do not enable GitHub Pages for the PBIP or Excel files. GitHub stores and distributes them; Power BI Desktop and Microsoft Excel are required to open the native artifacts.
