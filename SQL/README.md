# SQL Analytics Layer

## Files

- `schema.sql`: normalized dimensions and fact-table definitions
- `analytics_views.sql`: management reporting views
- `sample_queries.sql`: portfolio-ready FP&A query examples
- `integrated_fpa_analytics.db`: generated SQLite database

Example:

```bash
sqlite3 SQL/integrated_fpa_analytics.db
.tables
.read SQL/sample_queries.sql
```

The database is regenerated by the Python pipeline and should be treated as an analytical delivery artifact rather than a manually maintained source.
